## Google Material Symbols

The unchanged SVG files in `src/GameMode.Windows/Assets/Material` are Google Material Symbols, Rounded, 24 px.

- Source: https://github.com/google/material-design-icons/tree/master/symbols/web
- Guide: https://developers.google.com/fonts/docs/material_symbols
- License: Apache License 2.0. The complete text is bundled as `src/GameMode.Windows/Assets/Material/LICENSE.txt` and copied into published builds.
- Retrieved: 12 October 2026.

Game Mode renders these local SVG paths using WPF. It does not download fonts or icons at runtime.

## Project artwork

The PNG files in `src/GameMode.Windows/Assets/Brand` were supplied by the user for Game Mode. The originals are preserved. The contributor's requested display name is **vasilii-dev**.

`enabled.png`, `waiting.png`, and `off.png` represent the three mode states; `Icon.png` is the application icon; `exclamation.png` is the warning artwork; `vasilii-dev.png` is the author avatar. Windows ICO files are size exports of the supplied artwork, generated by `Tray/Assets/GenerateIcons.ps1`.

The reference screenshot used to guide the layout is not distributed as a Game Mode asset.
