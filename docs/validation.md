Политика выбора процессов проверена автоматическими тестами, а нативное управление — исключительно на одноразовом приложении.

Для read-only проверки на Windows:

```powershell
dotnet run --project tests/GameMode.WindowsChecks -c Release -- inspect
```

Для изолированной нативной проверки из корня репозитория (Game Mode должен быть выключен):

```powershell
dotnet build GameMode.slnx -c Release
$fixtureExe = (Resolve-Path .\tests\GameMode.TestTarget\bin\Release\net10.0-windows\GameMode.TestTarget.exe).Path
$fixtureProcess = Start-Process $fixtureExe -ArgumentList '--mib=240' -WorkingDirectory (Split-Path $fixtureExe) -PassThru
Start-Sleep -Seconds 2
dotnet tests/GameMode.WindowsChecks/bin/Release/net10.0-windows/GameMode.WindowsChecks.dll exercise $fixtureProcess.Id $fixtureExe
```

`exercise` отказывается работать с произвольным путём: допустим только `GameMode.TestTarget.exe` из `tests/GameMode.TestTarget/bin` и явно указанный PID. Повторите с `--mib=240 --ignore-close` для проверки принудительного варианта. Проверка сама убирает созданный повторно запущенный экземпляр; при неуспехе закройте оставшееся тестовое окно его кнопкой. Никогда не подставляйте PID или путь рабочей программы.
